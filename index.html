📌 핵심 구성 및 단축키

🖥️ 3열 분할 화면

[왼쪽] 실시간 웹 미리보기 (Live Preview)
[가운데] 소스 코드 편집기
[오른쪽] OpenCode 터미널 (AI 에이전트)

⌨️ 편리한 단축키

F12: 3열 화면 ↔ 전체 터미널 토글
Ctrl + Alt + V: 화면 배치가 흐트러졌을 때 원래 3열로 즉시 복원

⚠️ 사용자가 직접 눌러야 하는 단계 (중요!)

보안 정책 안내: AI 에이전트는 PC 보안 설정이나 권한 승인 창을 대신 누를 수 없습니다. 아래 화면이 나오면 직접 확인하고 클릭해주세요.

1. 작업 공간 신뢰 (Workspace Trust)

VS Code 실행 후 "Do you trust the authors of the files in this workspace?" 팝업이 뜨면 [Trust Workspace & Continue]를 눌러주세요. (제한 모드에서는 Live Preview 및 확장이 실행되지 않습니다)

2. 화면 제어 승인

AI가 화면을 검증할 수 있도록 AI 클라이언트(Codex 등)가 띄우는 컴퓨터/앱 제어 권한을 승인해주세요.

3. OpenCode AI 모델 연결

오른쪽 OpenCode 터미널에서 /connect를 입력하여 사용할 AI 모델(OpenCode Zen, OpenAI 등)을 연결하세요.

❓ 자주 묻는 질문 & 문제 해결

VS Code가 열렸는데 3열로 안 나뉘고 빈 창만 뜹니다.

상단에 "Restricted Mode"가 떠 있는지 확인하세요. 작업 공간 신뢰(Trust Workspace)를 승인하지 않으면 확장 기능이 동작하지 않습니다. 신뢰 승인 후 Ctrl + Alt + V를 누르면 3열 배치가 완성됩니다.

F12를 눌렀는데 반응이 없거나 다른 기능이 동작합니다.

노트북의 경우 Fn + F12를 눌러야 할 수 있습니다. 또한 반드시 바탕화면에 생성된 Vibe Coding - [프로젝트명] 전용 바로가기로 실행해야 단축키 설정이 적용됩니다.

내 기존 프로젝트에 적용하고 싶습니다.

AI에게 "내 프로젝트 경로(C:...)의 index.html을 대상으로 vibe-coding 환경을 적용해줘"라고 요청하면 기존 파일은 유지하면서 전용 바로가기를 생성해 줍니다.
