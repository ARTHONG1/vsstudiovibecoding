Vibe Coding

코드를 바꾸고 결과를 바로 확인하세요. AI 에이전트와 함께 완벽한 3대 뷰포트 환경에서 개발합니다.

🖥️ 3대 뷰포트 모드 (하단 상태바 버튼)

화면 맨 아래 오른쪽 구석의 전용 버튼으로 언제든 원하는 모드로 즉시 전환할 수 있습니다:

  • [ 🗖 터미널 전체 ] AI와 대규모 프롬프트 작성 및 빌드 로그 점검
  • [ 🌐 미리보기 전체 ] 에디터 노이즈 없는 1:1 고해상도 웹 UI 검수 (Computer Use 최적화)
  • [ ⊞ 3열 복원 ] 언제든 원래의 3열 분할 환경으로 즉시 복귀

🛠️ 진짜 브라우저 (Chrome/Edge) 원클릭 연동

가운데 코드 에디터 우측 상단 툴바의 ↗ 외부 브라우저 아이콘을 누르면, 시스템 기본 브라우저가 열리며 순정 F12 개발자 도구(Network, Application/쿠키)를 활용한 심층 검수가 가능합니다.

⌨️ 순정 단축키 100% 보존

  • F12: 순정 [함수/변수 정의로 이동] 정상 동작 (화면 가로채기 없음)
  • Ctrl + Shift + P: 명령 팔레트에서 Vibe Coding 검색 시 모든 제어 가능

🤖 공식 Codex AI 에이전트 & OpenCodex

오른쪽 3열 터미널에서 OpenAI 공식 Codex CLI가 실행됩니다. 로컬 OpenCodex와 자동 연동되어 Gemini, Claude, Solar 등 멀티 모델을 자유롭게 활용하며, Computer Use를 통한 화면 자율 검수와 지능형 코딩을 수행합니다.
